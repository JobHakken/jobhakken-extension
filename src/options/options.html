On job pages (LinkedIn, career sites), flags roles whose description explicitly rules out sponsorship — those requiring U.S. citizenship, a security clearance, “no sponsorship,” or export-control (ITAR/EAR) eligibility. Runs entirely on your machine (no AI). Off by default.

When off, a red “No sponsorship” mark is added to the job’s tile. When on, the job’s tile is hidden from the list. (LinkedIn shows the full description only once a job is opened, so a job is judged when you open it; the desktop app hides them upfront.)


Autofills a built-in placeholder identity (Jordan Rivera / example.com) instead of your real profile, so you can safely try it on live application pages without exposing anything. The toolbar popup shows a DEMO DATA banner while this is on. Turn off before real applications.


As you apply, this records the whole flow of each application — which fields autofill handled and which you filled in yourself — with your personal details scrubbed (emails/phones/long text reduced to placeholders; short answers like “Yes”/“LinkedIn” kept). It builds a local corpus that makes autofill smarter over time. Never touches the form, never leaves your machine, never captures other browsing. Export it to send for analysis.


Separate one-off tool: adds a Capture fixture button to the panel that downloads a scrubbed HTML snapshot + coverage report for engineering. Not needed for normal use — the auto-capture above is the corpus.
